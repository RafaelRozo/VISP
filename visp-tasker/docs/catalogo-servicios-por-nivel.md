# Catálogo de Servicios VISP / Tasker — Niveles y Desbloqueo

_Generado el 2026-07-23 desde la base de datos de producción (`visp_prod`). Total: **218 servicios** en **12 categorías**._

## Cómo funciona el desbloqueo

- Los **documentos son por SECCIÓN** (categoría), no por servicio. Una sección se marca 🔒 cuando contiene al menos un servicio que exige documento.
- Un proveedor **nuevo (L1)** puede ofrecer de inmediato **todos los servicios de nivel L1**, sin subir nada.
- Para los servicios **L2** de una sección 🔒: el proveedor sube **1 documento de sección aprobado** por un admin → sube a **L2** (desbloqueo global: aplica a los servicios L2 de todas las secciones 🔒).
- Para los servicios **L3**: requiere **licencia verificada + seguro de $2M** (oficios regulados). Un documento de sección no basta.
- Los servicios **L4 (emergencia)** están **en pausa**: hoy no se habilitan por ninguna vía.
- **Secciones abiertas** (sin 🔒): todos sus servicios están disponibles al registrarse.

| Leyenda desbloqueo | Significado |
|---|---|
| ✅ Disponible al registrarse | El proveedor L1 lo ofrece de inmediato |
| 📄 Documento de sección → L2 | Sube 1 doc de sección aprobado |
| 🎓 Licencia + seguro $2M (L3) | Oficio regulado |
| ⛔ No disponible | Emergencia (L4) en pausa |
